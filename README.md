# Dipan's Portfolio

A personal portfolio site built with React 18, TypeScript, Vite, and Three.js — showcasing
projects at the intersection of data science and equity research.

## About

I'm a third-year BSc Data Science student building toward equity research analyst roles,
working at the intersection of data science and Indian equity markets. This site showcases
that work, including **FraudShield**, an ML-based fake job posting detector.

## Built With

- [React](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Three.js](https://threejs.org/) for the 3D hero scene
- [Tailwind CSS](https://tailwindcss.com/)
- [EmailJS](https://www.emailjs.com/) for the contact form
